# 021 - 服务类别系统实现

## 概述
实现智能服务类别选择系统，为用户提供7大服务类别的清晰选择界面，确保用户能够准确选择所需的AI服务类型。

## 业务需求

### 功能需求
- **类别展示**：清晰展示7大服务类别
- **智能推荐**：基于用户输入推荐合适类别
- **快速切换**：支持类别间快速切换
- **类别说明**：每个类别提供详细说明和示例
- **使用统计**：记录类别使用偏好

### 服务类别定义
1. **数据分析服务**
   - 文件分析、数据可视化、报告生成
2. **内容创作服务**
   - 文档撰写、创意写作、内容优化
3. **图像处理服务**
   - 图像分析、风格转换、图像生成
4. **语音处理服务**
   - 语音识别、语音合成、语音分析
5. **代码生成服务**
   - 代码编写、代码审查、代码优化
6. **翻译服务**
   - 多语言翻译、本地化适配
7. **智能问答服务**
   - 知识问答、问题解决、咨询建议

export interface CategoryAPI {
  // 获取所有类别
  getCategories(): Promise<ServiceCategory[]>;

  getCategory(id: string): Promise<ServiceCategory>;

  // 智能推荐
  getRecommendations(input: RecommendationInput): Promise<ServiceCategory[]>;

  // 记录选择
  recordSelection(selection: CategorySelection): Promise<void>;

  // 获取使用统计
  getUsageStats(userId: string): Promise<CategoryUsageStats>;
}

// API响应格式
interface CategoryUsageStats {
  totalSelections: number;
  categoryFrequency: Record<string, number>;
  averageSessionTime: number;
  preferredCategories: string[];
}
