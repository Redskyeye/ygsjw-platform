# 任务017: PPT模板设计系统

## 📋 任务概述

设计并实现三套专业的面试辅导PPT模板系统，包括经典风格、现代风格和创意风格，满足不同行业和职位的面试展示需求，提供动态内容生成和实时预览功能。

## 🎯 具体要求

### 17.1 经典风格模板
- **设计特点**：简洁大方、专业稳重
- **配色方案**：深蓝+灰色+白色，商务配色
- **适用场景**：金融、咨询、国企、传统行业
- **页面构成**：
  - 封面页（个人信息+求职意向）
  - 个人简介页（基本背景+核心优势）
  - 工作经历页（时间轴+关键成就）
  - 项目经验页（项目详情+个人贡献）
  - 技能专长页（技能矩阵+熟练度）
  - 教育背景页（学历+专业+荣誉）
  - 结束页（感谢+联系方式）

### 17.2 现代风格模板
- **设计特点**：简约时尚、视觉冲击力强
- **配色方案**：渐变色+几何图形+现代字体
- **适用场景**：互联网、科技、新媒体行业
- **页面构成**：
  - 动态封面（个人照片+动态效果）
  - 能力雷达图（多维度能力展示）
  - 项目展示（瀑布流布局+数据可视化）
  - 技术栈展示（图标化技能展示）
  - 成就时间线（交互式时间轴）
  - 团队协作（团队角色+贡献）
  - 未来规划（职业规划+发展目标）

### 17.3 创意风格模板
- **设计特点**：个性化强、创意表现丰富
- **配色方案**：大胆配色+艺术元素+不规则布局
- **适用场景**：设计、创意、艺术、初创企业
- **页面构成**：
  - 艺术封面（个人品牌+视觉识别）
  - 创意简历（信息图表化展示）
  - 作品集展示（轮播图+详细说明）
  - 思维导图（知识体系+技能网络）
  - 创新案例（问题解决+创新点）
  - 个性化标签（性格特质+软技能）
  - 互动结尾（二维码+联系方式）

### 17.4 智能内容适配
- **行业适配**：根据行业自动调整内容重点
- **职位适配**：针对不同职位突出相应能力
- **经验适配**：根据工作经验调整内容深度
- **个性定制**：支持用户自定义颜色、字体、布局

### 17.5 动态元素支持
- **数据可视化**：图表、进度条、雷达图等
- **图标库**：行业图标、技能图标、装饰图标
- **动画效果**：页面切换、元素出现、强调动画
- **交互元素**：超链接、按钮、导航菜单

### 17.3 模板数据结构
```sql
-- PPT模板表
CREATE TABLE ppt_templates (
    id VARCHAR(50) PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    style VARCHAR(20) NOT NULL, -- classic, modern, creative
    description TEXT,
    thumbnail_url VARCHAR(500),
    preview_urls TEXT, -- JSON数组
    config_json TEXT, -- 模板配置JSON
    color_schemes TEXT, -- JSON，多个配色方案
    is_active BOOLEAN DEFAULT TRUE,
    usage_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 模板页面表
CREATE TABLE template_slides (
    id VARCHAR(50) PRIMARY KEY,
    template_id VARCHAR(50) REFERENCES ppt_templates(id),
    slide_order INTEGER NOT NULL,
    slide_type VARCHAR(50) NOT NULL,
    layout_config TEXT, -- JSON配置
    required_fields TEXT, -- JSON，必填字段
    optional_fields TEXT, -- JSON，可选字段
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 用户生成的PPT记录
CREATE TABLE user_presentations (
    id VARCHAR(50) PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    template_id VARCHAR(50) REFERENCES ppt_templates(id),
    interview_session_id VARCHAR(50) REFERENCES interview_sessions(id),
    title VARCHAR(200),
    content_data TEXT, -- JSON，用户内容数据
    file_path VARCHAR(500),
    pdf_path VARCHAR(500),
    status VARCHAR(20) DEFAULT 'draft', -- draft, generating, completed, failed
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
