# 任务016: 面试信息表单系统

## 📋 任务概述

设计并实现一个全面的面试信息收集表单系统，收集公司信息、职位详情、面试轮次、面试官类型等关键信息，为个性化的面试辅导提供数据基础。

## 🎯 具体要求

### 16.1 公司信息收集
- **公司名称**：必填，支持搜索推荐
- **公司规模**：创业公司(1-50人)、小型(51-200人)、中型(201-1000人)、大型(1000+人)
- **所属行业**：技术、金融、教育、医疗、制造等下拉选择
- **公司类型**：国企、私企、外企、创业公司、事业单位
- **融资阶段**：种子轮、A轮、B轮、C轮、D轮、上市公司
- **工作地点**：城市、办公地址、是否支持远程

### 16.2 职位详细信息
- **职位名称**：必填，智能推荐相似职位
- **职位级别**：实习生、初级、中级、高级、专家、管理层
- **薪资范围**：月薪范围或年薪范围
- **工作性质**：全职、兼职、实习、远程
- **核心要求**：技能要求、经验要求、学历要求
- **职位描述**：支持富文本编辑，可粘贴JD

### 16.3 面试流程信息
- **面试轮次**：技术面、HR面、总监面、CEO面、综合面
- **当前轮次**：记录当前进行到第几轮
- **面试形式**：现场面试、视频面试、电话面试
- **预计时长**：每轮面试的预计时间
- **面试时间**：具体的面试日期和时间

### 16.4 面试官信息
- **面试官类型**：HR、技术面试官、部门主管、高管
- **面试官数量**：每轮面试的面试官人数
- **面试官背景**：技术背景、业务背景、管理背景
- **关注重点**：技术能力、沟通能力、团队协作、学习能力

### 16.5 智能辅助功能
- **信息补全**：根据公司名称自动补全基本信息
- **职位分析**：基于职位名称分析常见面试问题
- **行业特点**：根据行业推荐面试准备重点
- **经验分享**：显示其他用户的面试经验（匿名）

### 16.8 数据库设计
```sql
-- 面试信息主表
CREATE TABLE interview_sessions (
    id VARCHAR(50) PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    company_name VARCHAR(200) NOT NULL,
    company_size VARCHAR(50),
    industry VARCHAR(100),
    company_type VARCHAR(50),
    funding_stage VARCHAR(50),
    location TEXT,
    remote_work BOOLEAN DEFAULT FALSE,
    position_title VARCHAR(200) NOT NULL,
    position_level VARCHAR(50),
    salary_range VARCHAR(100),
    work_type VARCHAR(50),
    requirements TEXT,
    position_description TEXT,
    current_round INTEGER DEFAULT 1,
    interview_format VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 面试轮次表
CREATE TABLE interview_rounds (
    id VARCHAR(50) PRIMARY KEY,
    session_id VARCHAR(50) REFERENCES interview_sessions(id),
    round_type VARCHAR(50) NOT NULL,
    round_number INTEGER NOT NULL,
    status VARCHAR(20) DEFAULT 'upcoming',
    scheduled_time TIMESTAMP,
    duration INTEGER, -- 分钟
    interviewer_type VARCHAR(50),
    interviewer_count INTEGER DEFAULT 1,
    focus_areas TEXT, -- JSON格式存储关注重点
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 公司信息库
CREATE TABLE company_database (
    id SERIAL PRIMARY KEY,
    name VARCHAR(200) UNIQUE NOT NULL,
    size VARCHAR(50),
    industry VARCHAR(100),
    type VARCHAR(50),
    funding_stage VARCHAR(50),
    description TEXT,
    website VARCHAR(500),
    headquarters TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
