# 任务018: 双Webhook数据流系统

## 📋 任务概述

构建双Webhook数据流处理系统，实现信息解析和PPT生成的全自动化流程。第一个Webhook负责接收和解析用户提交的面试信息，第二个Webhook触发PPT生成任务，实现端到端的自动化处理。

## 🎯 具体要求

### 18.1 信息解析Webhook（Webhook A）

- **接收功能**：接收来自前端表单的面试信息数据
- **数据验证**：验证数据完整性和格式正确性
- **智能解析**：解析简历文件，提取关键信息
- **数据标准化**：将不同格式的数据标准化处理
- **错误处理**：提供详细的错误反馈和修正建议

### 18.2 PPT生成Webhook（Webhook B）

- **触发条件**：接收到解析完成的数据后自动触发
- **模板匹配**：根据行业和职位智能匹配最佳模板
- **内容生成**：基于用户数据生成个性化PPT内容
- **异步处理**：支持大文件和复杂任务的异步处理
- **进度通知**：实时更新处理进度和状态

### 18.3 数据流管理

- **状态跟踪**：跟踪每个请求的处理状态
- **队列管理**：处理高并发请求的队列机制
- **重试机制**：失败任务自动重试和降级处理
- **日志记录**：完整的处理日志和审计追踪
- **性能监控**：实时监控处理性能和系统健康度

### 18.4 安全机制

- **身份验证**：Webhook调用方身份验证
- **数据加密**：敏感数据传输和存储加密
- **访问控制**：基于角色的访问权限控制
- **防重放攻击**：防止重复请求和恶意攻击
- **数据脱敏**：日志中敏感数据脱敏处理

### 18.5 监控和告警

- **健康检查**：Webhook服务健康状态监控

### 18.7 Webhook B - PPT生成服务

```python
# webhooks/ppt_generator.py
from celery import Celery
from services.ppt_service import PPTService
from services.template_matcher import TemplateMatcher

celery_app = Celery('ppt_generator')

@app.route('/webhook/generate', methods=['POST'])
def generate_ppt():
    try:
        # 身份验证
        if not authenticate_request(request):
            return jsonify({'error': 'Unauthorized'}), 401

        data = request.get_json()
        session_id = data.get('session_id')

        # 异步任务处理
        task = generate_ppt_async.delay(data)

        return jsonify({
            'success': True,
            'task_id': task.id,
            'session_id': session_id,
            'status': 'queued'
        })

    except Exception as e:
        logger.error(f"Webhook B error: {str(e)}")
        return jsonify({'error': 'Internal server error'}), 500

@celery_app.task(bind=True)
def generate_ppt_async(self, data):
    """异步PPT生成任务"""
    try:
        session_id = data['session_id']

        # 更新状态：处理中
        update_task_status(session_id, 'processing', 0)

        # 模板匹配
        matcher = TemplateMatcher()
        template_id = matcher.match_best_template(data)

        # 更新状态：模板匹配完成
        update_task_status(session_id, 'processing', 20)

        # 生成PPT
        ppt_service = PPTService()
        result = ppt_service.generate_presentation(
            template_id=template_id,
            user_data=data,
            progress_callback=lambda p: update_task_status(session_id, 'processing', 20 + p * 0.7)
        )

        # 更新状态：完成
        update_task_status(session_id, 'completed', 100, result)

        return result

    except Exception as e:
        logger.error(f"PPT generation failed: {str(e)}")
        update_task_status(session_id, 'failed', 0, {'error': str(e)})
        raise

def update_task_status(session_id: str, status: str, progress: int, result: dict = None):
    """更新任务状态"""
    from models.task_status import TaskStatus

    TaskStatus.update_status(
        session_id=session_id,
        status=status,
        progress=progress,
        result=result,
        updated_at=datetime.utcnow()
    )
```

### 18.9 前端状态监控组件

```typescript
// components/WebhookStatus/WebhookStatusMonitor.tsx
interface WebhookStatusProps {
  sessionId: string;
  onCompleted?: (result: any) => void;
  onError?: (error: string) => void;
}

const WebhookStatusMonitor: React.FC<WebhookStatusProps> = ({
  sessionId,
  onCompleted,
  onError
}) => {
  const [status, setStatus] = useState<WebhookStatus>({
    step: 'pending',
    progress: 0,
    message: '等待处理...'
  });

  useEffect(() => {
    const ws = new WebSocket(`${WS_URL}/webhook-status/${sessionId}`);

    ws.onmessage = (event) => {
      const data = JSON.parse(event.data);
      setStatus(data);

      if (data.status === 'completed') {
        onCompleted?.(data.result);
      } else if (data.status === 'failed') {
        onError?.(data.error);
      }
    };

    return () => ws.close();
  }, [sessionId]);

  return (
    <div className="webhook-status">
      <ProgressBar progress={status.progress} />
      <StatusMessage message={status.message} />
      <StepIndicator currentStep={status.step} />
    </div>
  );
};
```
